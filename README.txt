MIN LP-SAMLING v2.1

Denne versjonen retter feilen der slettede duplikater kom tilbake etter at appen ble åpnet på nytt.

Viktig:
- Samme lagringsnøkkel som før brukes.
- Eksisterende samling beholdes.
- Den gamle IndexedDB-databasen importeres ikke når dagens samling finnes.
- Migreringen merkes permanent som ferdig og kjøres ikke på nytt.
- Ingen plater slettes automatisk i oppdateringen.

Last opp alle filene til samme GitHub-mappe og samme nettadresse som før.
